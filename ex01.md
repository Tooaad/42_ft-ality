### Transiciones y Lista de Estados Iniciales
```
δ : Q × Σ → Q

let transition state symbol =
  match state, symbol with
  | Q0, Zero -> Q0
  | Q0, One  -> Q1
  | Q1, Zero -> Q0
  | Q1, One  -> Q1
```
